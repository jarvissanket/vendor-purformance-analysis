# vendor-purformance-analysis📊 Vendor Performance & Inventory Analysis

This project focuses on analyzing vendor-wise sales and inventory data to evaluate vendor performance and identify opportunities for inventory and profitability optimization.

🔹 Key Objectives

Analyze vendor sales contribution and profitability

Calculate unsold inventory value and identify blocked capital

Evaluate profit margins across vendors

Provide actionable business insights for better procurement decisions

🔹 Key Steps

Data cleaning and preprocessing using Pandas

Feature engineering for business metrics (Unsold Inventory Value, Profit Margin)

Exploratory Data Analysis (EDA)

Vendor performance segmentation and threshold-based analysis

🔹 Tools & Technologies

Python

Pandas, NumPy

Jupyter Lab

🔹 Key Outcomes

Identified high-performing and low-performing vendors

Highlighted vendors with high unsold inventory and low profit margins

Delivered data-driven recommendations for inventory optimization
